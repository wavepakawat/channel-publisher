Channel Publisher

A private command-line tool for publishing my own videos.

Channel Publisher uploads finished videos from my computer to YouTube channels that I own. It works with YouTube through YouTube API Services. It sets each video's title, description, tags, category, privacy status and synthetic-media disclosure from the files of that video.

The tool is used only by its developer. It is not offered to the public, it has no user accounts, and it does not access channels owned by anyone else.
